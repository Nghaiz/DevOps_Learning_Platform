# P16 landing rebuild: practical DevOps workbench

Date: 2026-09-12 implementation, completed after midnight 2026-09-13 (Asia/Bangkok).

## Decision and scope

User explicitly rejected both the original white 3D ring and its replacement orbit illustration. Entire landing composition replaced. No decorative ring, ellipse, scroll-driven scene, or card grid remains in marketing. Arena keeps its own Three.js dependencies and behavior.

Owned files: apps/web/src/components/marketing/**, apps/web/src/app/page.tsx, apps/web/src/app/home-cta.tsx, packages/copy/src/surfaces/home.ts and this report. Other agents own backend, shell, e2e and final build.

## Composition

1. Opening: large left-aligned “Học DevOps. Tự tay vận hành.” headline, concise purpose and account-aware action. Headline and supporting copy share one horizontal composition on desktop and stack naturally on mobile.
2. Full-width practice workbench: task brief beside a meaningful terminal demonstration. Linux, Docker, Kubernetes native controls choose examples. No arbitrary product illustration.
3. Compact published-content count strip: retained existing server data reader, error behavior and independent Suspense boundary. No invented activity or learner statistics.
4. Continuous curriculum list: four authored paths, thin row dividers, descriptions grounded in content/paths. Rows navigate to verified IDs.
5. Practice explanation: introductory text alongside an ordered definition list explaining sandbox, grading, progress and environment setup.
6. Closing: decisive type treatment, account-aware action, short identity line.

## Interaction and accessibility

- `data-testid="landing-lab-preview"` owns demo; default topic Docker.
- Native buttons Linux / Docker / Kubernetes expose `aria-pressed`. All remain keyboard reachable without a custom key model.
- “Chạy ví dụ” reveals deterministic local output and explanation. It becomes disabled “Đã chạy ví dụ”. “Đặt lại ví dụ” clears the output. Changing topic clears stale output.
- Output: `id` and `data-testid` both `landing-demo-output`, polite atomic live region.
- Console: labeled region. Decorative icons hidden from assistive technology.
- Visible disclosure: “Bản minh hoạ tương tác”; terminal footer explicitly says sample output, no sandbox connection. Real sandbox only opens through authenticated learning flows.
- Guest CTA opens /register, member CTA /lessons. “Xem lộ trình” scrolls to page curriculum. Curriculum copy explicitly states login is required.
- Focus outlines have offset, mobile targets >=44px, code wraps inside terminal, no horizontal page scrolling intentionally introduced.
- No autoplay, canvas, scrolling event handlers or WebGL feature probes. Only row hover transition; reduced-motion disables it.

## Design standards

Preserve existing Be Vietnam Pro and system monospace, including Vietnamese diacritics. All colors consume existing semantic CSS variables; no raw colors, new theme tokens, font downloads or CSP relaxation. Red primary acts as selected topic/action emphasis. Thin separators organize a continuous page. Only the workbench is a framed application surface.

Mobile-first CSS starts at320px and enhances at768px/1100px. Type uses rem-aware clamp values. Semantic token inversion gives the light-theme terminal contrast; dark theme uses existing card/foreground roles.

All UI text, including terminal examples and control labels, passes through the home copy surface. Removed obsolete home.loop.*, home.stage.*, home.art.* and old steps copy. Retained honest published counts and OpenGraph copy.
