## Result

- Migrated 466 remaining UI literals from 31 product files, including all 13
  author field/helper files, the 10 problem field files and seven production
  problem helpers. `vocabulary.ts` labels describe options in the editor and
  therefore belong in mapped UI copy. User-authored lesson content, technical
  identifiers and test lesson data remain data.
- Added 44 structured error entries with `what` and actionable `next` and
  connected callers through `errText`. Removed obsolete implementation details
  about database foreign keys and a historical sandbox timing from author UI.
- `author` now has 358 keys and `problem` has 240. The previous empty-problem
  exemption is removed. The problem lane has no deferred product file; its
  sole explicit fixture exemption is guarded against production imports.
- `PROBLEM_TOPIC_LABELS` and `PROBLEM_DIFFICULTY_LABELS` retain their public
  exports and complete enum coverage, but resolve text through `problem.`.
  Games declares its workspace copy dependency; copy retains zero runtime
  dependencies and no dependency on games.
- `CopyRef` is a correlated union: static keys cannot take parameters and
  dynamic keys require their exact parameter names and types. Static selector
  tables use `StaticTextKey`. Compile-time positive/negative controls preserve
  this guarantee across `renderCopy`.
- The new AST gate covers all five directory trees, detects Vietnamese and
  escaped literals, JSX text, English UI attributes, labels and templates.
  It distinguishes comments, CSS, technical identifiers, punctuation, generic
  arrows and actual UI copy. `TrialStepPlan.label` stays the server's stable
  script identifier; its sibling `description` remains fully scanned.
- Auth copy now supports the real reset backend, with obsolete unavailable
  messages removed. The reset request confirms acceptance only and uses the
  same wording regardless of account existence or recipient rejection.
