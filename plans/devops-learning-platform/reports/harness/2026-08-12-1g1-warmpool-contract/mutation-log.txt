GOTCHA QUY TRINH — se can bat ky ai lap lai kieu kiem nay
---------------------------------------------------------
Hoan nguyen dot bien bang `git checkout -- <file>` la SAI trong bo canh nay:

  - File DA SUA ma CHUA COMMIT: git checkout dua no ve HEAD, tuc XOA SACH phan
    sua. O luot dau tien no da xoa toan bo W2 trong reaper.go (struct field,
    tham so cua New, nhanh switch, staleImage, sandboxImageOf, doc-comment).
    Phat hien ra vi reaper_test.go — file KHONG bi checkout — goi mot signature
    khong con ton tai.

  - File CHUA TRACK (trim.lua moi tao): git checkout bao
    "pathspec ... did not match any file(s) known to git" va DOT BIEN O LAI
    nguyen trong file. Neu khong doc ky output thi buoc tiep theo se chay tren
    ma da bi dot bien.

Duong dung: doc file vao mot bien truoc khi dot bien, ghi lai tu bien sau khi
chay xong. Bang o tren duoc dung lai theo cach do.
