- M2: side-by-side toggle (aria-pressed) for IDE content, both rows mounted, `hidden` without display utility.
- M3: IdePane overlays on expired/error, re-probes on new session id, retries 404/408/409/425/429 (only 401/403 are permanent).
- M5/M6: check results keyed by step key (lesson) and attemptId:taskId (lab) with a per-run seq; Check disabled unless phase === 'ready', reason shown as text.
- M7: single bar, NoticeStrip (worst first, collapsible, dismissible), check result docked in the instructions column.
- Exec buttons on code blocks disabled with a visible reason (`execBlockedReason`).
- Diagram blocks: full-width figure + caption, click opens a zoom Dialog (keeps `diagrams[src].svg`).
- Check output: `parseCheckCriteria` rendered as a ✓/✗ list + notes, for fresh and saved results.
- Workspace always night (`.dark` scope); terminal theme defaults to `dlp-dark` regardless of app theme (explicit profile choice still wins).
- 0c API change: Esc then Tab hint; lazy surface no longer forces `focusNextAfter` (Shift+Tab goes backward).
