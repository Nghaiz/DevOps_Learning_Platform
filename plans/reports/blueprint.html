04 · Cô lập sandbox

Cho user quyền root — an toàn

Vấn đề số 1: root-trong-container không được = root-trên-host. Pod K8s thường không đảm bảo điều đó. Chiến lược hai tầng.

05 · Bảo mật

10 luật rút thẳng từ pentest

Nền tảng đối thủ (devops.toiyeuptit.com) đã bị chiếm root shell qua đúng pattern này. Mỗi lỗ hổng tìm được trở thành một yêu cầu bắt buộc — thiết kế để không lặp lại.

IDOR PATCH /users/{id} — student sửa admin
Object-level authz mọi resource, kiểm tra server-side
CORS reflect mọi origin + credentials
Allowlist origin chính xác, không reflect, không Allow-Credentials:*
NoSQLi username[$ne]=null dump DB
PostgreSQL + validate/cast input bằng Zod — diệt gốc
Info leak size=1000000 → 747 users
Pagination cap cứng (max 100) server-side
DoS payload 10MB → 502
Body-size limit + rate limit tại gateway
JWT token student dùng chéo admin panel
JWT có aud, key ký riêng, TTL ngắn + refresh rotation
Refresh endpoint nhận access token
Refresh token riêng, xoay vòng, revocation list
Token in URL /impersonate-callback?accessToken=
Token chỉ trong cookie httpOnly / POST body
Headers thiếu HSTS/CSP/X-Frame-Options
Bật đủ security headers qua helmet middleware
Escape root thoát ra VM, lộ docker.sock
Sysbox + drop caps + seccomp/AppArmor + NetworkPolicy deny-all + chặn metadata + authz per-session trên WS
06 · Chịu tải cao

Sáu cơ chế chịu tải

Pre-warmed pool

Giữ N sandbox sẵn, claim sub-second, replenish async.

TTL + reaper

Tuổi thọ cứng 30–60′ + idle timeout, controller dọn hết hạn.

Resource quota

CPU/mem/PID/pod + ResourceQuota — chặn fork-bomb.

Autoscaling

Karpenter/CA, node pool riêng có taint cho lab.

Cost control

Spot node, scale-to-zero off-peak, đẩy game sang frontend-only.

WS scale-out

Session-affinity, LB idle-timeout, ping, map ở Redis.
